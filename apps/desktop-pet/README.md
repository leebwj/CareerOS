# desktop-pet — CareerOS in your system tray

Lives next to the clock. **Hover** the tray icon for today's headline numbers;
**click** it for the brief with the actual roles, each linking straight to the
application. Starts at login, so opening your laptop is enough.

```bash
cd apps/desktop-pet
npm install
npm start
```

The tray icon is a cobalt dot (`assets/tray.png`, generated by `node make-icon.mjs`
— no image dependency). Right-click it for: show/hide the brief, open the
tracker, open prep, toggle start-at-login, quit.

## How it gets its data

It fetches [`brief.json`](../role-grabber/data/brief.json), which the
role-grabber regenerates **4×/day on GitHub Actions**. That file carries the
headline counts *and* the top 8 roles behind them, so the pet can name a role
rather than just count them. Nothing depends on this machine being on.

> It used to read `apps/secretary/out/brief.md` off local disk. That file only
> changes when someone runs the script by hand, so the pet was reporting days-old
> numbers as if they were current. Don't reintroduce a local-file dependency.

## The character

Optional — it only appears when you summon it from the tray. Its internal
geometry is 120px and a wrapper scales it, so **`--pet-scale` in `index.html`
resizes the whole thing** and nothing inside needs touching. Swap `#pet`'s
contents for your own art.

## Gotchas worth knowing

- **Don't name a top-level renderer variable `pet`.** The preload exposes
  `window.pet` through contextBridge as a non-configurable property, so
  `const pet = …` throws *"Identifier 'pet' has already been declared"* and kills
  the entire script — the window still appears, just inert. Renderer console
  output is piped to the terminal precisely because that failure is invisible.
- **`setLoginItemSettings` needs an explicit path + args when unpackaged**,
  otherwise it registers bare `electron.exe` and next login opens Electron's
  welcome app instead of this one.
- Transparency, always-on-top and click-through are compositor behaviour and
  can't be verified headlessly — check them on screen.
